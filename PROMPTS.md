# PROMPTS.md

## AI Tool Usage

AI assistance was used during the development of BalanceVault for guidance, debugging, code review, documentation, and test planning.

## Main Development Tasks

### 1. Project Architecture
- Helped plan the React frontend and Spring Boot backend.
- Discussed PostgreSQL database integration.
- Reviewed the separation of controllers, services, repositories, and entities.

### 2. Authentication and Authorization
- Assisted with Spring Security configuration.
- Reviewed BCrypt password hashing.
- Implemented role-based access for ACCOUNT_HOLDER, ADMIN, and AUDITOR.
- Reviewed first-admin bootstrap functionality.

### 3. Financial Integrity
- Discussed double-entry ledger accounting.
- Reviewed idempotency-key handling to prevent duplicate transactions.
- Reviewed account locking and transaction concurrency protection.
- Checked overdraft prevention and transaction validation.

### 4. Account Management
- Assisted with account request and administrator approval workflows.
- Reviewed account request status handling.

### 5. Testing and Debugging
- Assisted with debugging PostgreSQL and Spring Boot startup issues.
- Helped write unit tests for insufficient balance and idempotency scenarios.
- Reviewed API responses and application behavior.

### 6. Documentation
- Assisted in preparing the README, threat model, and API documentation.

## Important Note

AI assistance was used as a development aid. The project code, configuration, testing, and final submission should be reviewed and understood by the project developer. AI-generated suggestions were not treated as a substitute for verification.
